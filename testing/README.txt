================================================================================
TESTING FOLDER
================================================================================

This folder contains test queries for manual database exploration.

================================================================================
FILES
================================================================================

test_queries.sql
  → Ready-to-run SQL queries with real values (no ? placeholders)
  → Safe to execute in SQLTools or any SQLite viewer
  → Includes examples of all CRUD operations
  → Bonus queries for data analysis (COUNT, GROUP BY, etc.)

================================================================================
HOW TO USE
================================================================================

1. Connect to the database in SQLTools (TodoDB_Test connection)
2. Open test_queries.sql
3. Highlight any query you want to run
4. Press Ctrl+E Ctrl+E (or right-click → Run Query)
5. View results in the output panel

================================================================================
PURPOSE
================================================================================

Use this folder to:
  → Test database queries manually
  → Explore data without running the Python app
  → Learn SQL by experimenting with real data
  → Verify data changes after app operations

The queries/ folder shows what the app uses.
The testing/ folder is where you experiment.
